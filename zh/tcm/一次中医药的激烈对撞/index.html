一次中医药的激烈对撞

📅 2026年08月21日  ·  ☕ 13 分钟  ·  ✍️ 医行天下 · 👀... 阅读
    🏷️
  • #茶话会


序 中医药现状

主持人： 为什么以前非常好用的中药，现在却比较少见？中药效果差的原因是什么？为什么说传统医学亡于中药？

百病源于浊缠身，食饵辟谷静身心。我们将用心搭建起一座连接古老智慧与现代生活的桥梁，让传统的道家医学照亮您的健康之路。欢迎主讲嘉宾道家纳清排浊法传承人、归元动气针发明人、道家医学推广者张蕴迁。

张老师，最近我刷短视频，看到有人宣扬说：她不相信中医，也不信中药，意思就是让大家都不要信。

来自短视频的信息

今天想和大家分享的是：我不信中医，更不信中草药。所以现在有时候去医院看病的时候，就会问大夫，请不要给我开中药。

张老师： 其实出现这种局面，我挺心痛的。大家伙儿知道，过去中医看病的效果非常好。你看过去有病的，找个老大夫开个方儿，三付五付就见效了。现在呢效果不佳，别说三付五付了，没喝一个月它都不一定见效。

你看我认识一个老大夫，90多岁。有一次他跟我讲，他说现在咱们不能怨老百姓骂中医。老百姓为什么骂？因为现在中药不灵了，而且价格又涨得这么厉害，假冒伪劣又这么严重。花钱多还没效果，老百姓怎么能不骂呀？

壹 行家解析

主持人： 张老师，您昨天也讲了，现在大家觉得传统医学的效果差，其实很大一部分问题是出在中药上。

张老师： 对。我们知道药材决定了药效，药材好，药才能好。中药效果不好的原因其实挺多，首先，有些好的中药咱们用不到。

1、体外培育的 / 牛黄

张老师： 比如说流传了百年、大名鼎鼎的中药抗瘤第一药叫西黄丸。它在古代能把病人身上的增生、结节、息肉、囊肿一网打尽，因为西黄丸具有清热解毒、消肿散结的作用。

但是，现在西黄丸几乎起不到这些作用。为什么？因为效果好的西黄丸，大家伙用不到。

这个方子其实还是原来那个方子，就四味药，很简单。剂量也还是那个剂量，但药材不是以前那个药材。就连咱们国内中药的第一品牌同仁堂的西黄丸，用的都是体外培育的牛黄、人工的麝香。

为啥这么改？牛黄是啥？牛的胆结石，天然形成的，非常稀少。杀一百头牛，也不一定能提取到一克牛黄。

为什么这么少？因为只有五岁以上的老牛才可能长出牛黄，而普通的牛两岁就出栏送到屠宰场，所以天然牛黄非常稀少，一直都处于供不应求的状态。

一克天然牛黄能达到两千块钱，比黄金还贵上好几倍。但是有钱你也买不到，所以就用人工牛黄替代。虽然解决了产量问题，但却缺乏天然牛黄的某些微量元素和活性物质，效果上大打折扣。

2、买不到的 / 麝香

张老师： 还有麝香。

现在用的是人工的。因为天然麝香，有钱你也买不到。

为什么？因为麝属于国家一级重点保护动物。之前有八个人也盗取过天然麝香，价值两百万，不过现在这些人都被关进去了。

保护野生动物是应该的，但也确实影响到了很多珍稀名贵药材的使用。穿山甲、犀角、羚羊角，这些药材现在都用不到了。咱也不能说完全用不到，但是价格现在都已经是非常的昂贵。

主持人： 我们说一部分的好药材被禁止使用了，它确实会影响药效。除了这种用不上的药材，能用上的药材的质量，您昨天也说是一言难尽。

张老师： 没错，现在大部分中药的质量真是堪忧。现在中药跟过去中药都没法比，都不是缩水这么简单的。现在假冒伪劣的中药也太严重了，比如说一些贵重药材，那是假冒伪劣的重灾区。

3、换了皮的 / 阿胶

张老师： 比如说阿胶，正常是驴皮，是不是？而且是东阿的阿胶。为什么用东阿县的？因为东阿的水好。

换个其他地方，也是驴皮，可能效果也没有那么好。但最起码还是驴皮，对不对？但是现在很多不良商家用猪皮、骡子皮，这还算是好的，他没给你拿皮鞋熬就不错了。

主持人： 对啊，我也在想，它至少是一个能吃的。

张老师： 对，很多还有明胶兑的呢？所以说，这个本身就是一个问题。

4、被提炼过、啤酒泡的 / 虫草

张老师： 还有虫草。

去市场上买，不敢说一半是假的，但是这个药基本都是药渣子。它就是有效的成分已经被提炼过了，它就是个已经被提炼过药效以后的东西。

就像我们有的时候去买沉香，你会发现它只有一点淡淡的味道，很轻。为什么呢？沉香有的是被抽油的，就是我们说沉香里面的沉香油已经被抽走了，留下的只有沉香的木头。你说它还有用吗？

就像我说的虫草，也一样。所以很多老同志买的冬虫夏草真便宜，但效果几乎没有。

还有黑心的药材商，把提炼过的虫草用啤酒给你泡。用啤酒泡完之后，颜色也对、重量也对，也鼓鼓溜溜的，然后他再卖你。你说普通老百姓也不是搞专业、搞药的，能鉴别出来吗？

主持人： 肯定鉴别不出来。

5、掺葡萄皮的 / 山萸肉

张老师： 再比如山萸肉（补益肝肾，收敛固脱），山茱萸的果肉，山萸肉这个药是很好的。六味地黄丸、知柏地黄丸，凡是归地黄丸里边都有山萸肉。本身这个药比较好，补肝补肾。

有糖尿病的、高血压的、糖尿病肾病的、尿蛋白有泡沫，上医院一化验一检查，尿常规有蛋白的。这病搁西医西药，不好治。传统医学要治呢，辨证之后加上山萸肉、莲子、芡实、巴戟天，还能把尿里的蛋白给收回来。

山萸肉这药确实不错，但是产量低。产量低，它就贵。黑心药商挣不义之财，往山萸肉里边掺东西。掺什么？葡萄皮儿。吃着也酸溜溜的，跟真的差不多，颜色也像，手一捻感觉也对。

本来用山萸肉，可能用15、20g收尿蛋白也可以了，能治肾炎、糖尿病肾病。如果掺上葡萄皮儿呢？用15g山萸肉，结果里面一半是葡萄皮儿，能管用吗？不好使。

6、注胶的 / 鱼胶

张老师： 还有药材，用硫磺熏的。还有里面有些注胶的，比如鱼胶（海洋人参，胶原蛋白，微量元素）。

鱼胶，南方用得比较多。女的说它的蛋白能够养颜、美容，它本身用于男子无精、少精症是非常好用的，单用一味鱼胶治疗都非常好。

但是现在外面卖的鱼胶，里面加增重粉，你也不知道它是什么东西。比如原来它一个是5克，加完以后可能就重10克。

原来说一斤，比如说称100个头，一个5克的码，比如说称100个头就是500克，对不对？但是它这个情况只称50个头。但这里边不是有效成分，它是加了增重胶、增重剂了，怎么用？是不是？

贰 敲响警钟

张老师： 就像这种事情真的是很多，所以你看看药材假冒伪劣，这是很闹心的一个事。

近几年，不少人说中医将亡于中药。要我说，它是亡于失德。医药，说白了是个良心活。中药是救人的，你不能害人。

主持人： 对，我觉得张老师说的对。我们做人是以德为先，特别是医药领域的从业人员。

张老师： 对。这些年，媒体对中药造假进行了一系列的曝光，也在不断敲响警钟。

来自中药材集散地的调查

“独活冒充当归，染色的扁豆冒充酸枣仁。还有从药厂回收的那些已经没有药效的药渣，通过烘干做二次加工，被包装成正品药材销售。

这次3·15，中药造假又一次被点名。

其实前两天，《新京报》记者在全国最大的中药材集散地、素有中华药都之称的安徽亳州调查发现：中药材网购乱象丛生，消费者网购中药材的风险非常大。

他说：普通人网购中药材，能不能买到真货全凭运气。这是报道中中药材商家的原话，这句话不禁让人不寒而栗。

不管有多少人在黑我们中医，我一直相信大部分中国人还是相信中医的，因为中医离我们太近了。四季养生、时令节气、烹煮烹调，生活的方方面面都有中医的智慧。

在中国，中医不仅仅是一种治疗手段，更是一种文化基因和生活方式，要想灭亡我们的中医是天方夜潭。但是如果像报道里这种情况长此以往这样糟践，那中医的灭亡就真的不是一句口号了。”

张老师： 中药质量堪忧的新闻层出不穷，看得也是后背直发凉。明明诊断也对，方儿也对，药材不对，病人就是治不好，这也是非常要命的一件事。

叁 道地药材

张老师： 好药材除了有些买不到，有些不是真的，出现最多的就是咱们说老百姓用不上道地药材。

主持人： 药材不就行了吗？道地的药材又会有这么大的影响吗？

张老师： 当然。中医不有一句话？橘生淮南为橘，淮北为枳。产地不同，药效也不一样。

为什么大家一说到某种水果，那个地方的苹果好，那个地方的梨好，那个地方的牛肉好，这个地方的鱼好。那么这个鱼这个苹果，它不是就在这一个地方长吧？为什么这个地方的好？土不一样。

所以我们讲一方水土养一方人，药材也一样。药王孙思邈也说过用药必依土地，强调产地问题。用古人话说“采天地之灵气，受日月之精华”，是有道理的。

现代研究表明了独特的土壤、光照、水分，造就了独特的药效。像天山的雪莲、宁夏的枸杞、东北的人参、文山的三七、焦作的山药，这都是道地的好药材，对吧？但是换个地方种？效果不行。

1、原产地的 / 怀山药

张老师： 说到这儿，我又想起一件事儿。日本一直在学习咱们的中医中药，而且还想占为己有。

据说当年日本人为了研究怀山药，专门用船把河南的土壤运回到日本。分析土壤成分，重新配置。结果呢？种出来的山药药性也是大大下降。这说明什么？产地直接决定药效。产地不对，就不是道地药材。

李时珍曾在《本草纲目》记载，说“性随地变，质与物迁”，讲的就是中药药性与地域的关系。

中医认为，各地的土壤、气候等条件都不一样，所产药物的药性不同，也存在差异。所以古人也是通过实践，总结了哪味药材在什么地方的药性最好。这是它的实性和生物特性所决定的，而不是单纯里边的成分问题，古人管这个才叫道地药材。

主持人： 所以说光是药材还不行，还必须是原产地的药材才能被叫做道地药材。

2、不管事儿的 / 鱼腥草

张老师： 其实道地药材，不光是对产地有要求，种植方式、采收炮制都有要求。棚里的、陆地生的，它就是种植方式的问题，种植方式也是影响药效。

毫不客气地讲，现在中药本身都有病了。你还拿它治病，能行吗？肯定没效。

举个例子，有一个药叫鱼腥草（清热解毒，消肿疗疮，利尿除湿），很常见。鱼腥草治肺炎发热，治疗肺部感染、发烧，挺好使。

我曾经下乡义诊，有时候去山沟里、农村。这地方很多人，到了天冷的时候有气管炎、大叶型肺炎，现在大叶型肺炎都不多见了。

医疗条件差的地方，有病不像现在 —— 有病及时到医院拍个片，及早用药，不会说感个冒就发展成大叶型肺炎。山沟老百姓有病，都是“小病挺，大病扛，挺不住了见阎王”，是不是？都这个路子。

当年下乡义诊的时候，能遇见很多大叶性肺炎的病人。这个时候怎么治？基本上就是千金苇茎汤。这个方子用鱼腥草和败酱草，退热消炎是很好用的。花不了多少钱，病人的炎症就能控制住，退热也快。

现在别说大叶性肺炎，普通支气管炎、肺部有轻微炎症的病人，加鱼腥草进去它不管事儿了。

为什么？过去鱼腥草都是野生的。长哪儿？深山老林的水沟里、小溪里、泉眼、岸两边。那些野生鱼腥草，味儿特别大。熬一熬就真的是药汤子，跟鱼汤一样新鲜的味儿。

现在的鱼腥草怎么来的？药农把鱼腥草的籽儿撒在庄稼地里，像种菜似的。

因为地本身是农用地，农用地都已经经过多年化肥农药熏了，是不是？这样的地里长出来的鱼腥草，它本身都是化肥、农药的残留。鱼腥草本身带着病，能有效吗？

再说了，原来在溪流、河边、水边上长，地气串的和水气串的，它就有不同特性。就像我们药炮制的时候，拿地气串一串，为什么？地气属阴，它有收敛作用是一个道理，所以这个情况它怎么有效？

3、农残的 / 人参

张老师： 再说人工养殖的人参 —— 农残，效果还差。一百根园子参抵不过一根儿野山参。别说野山参，林下参都不好使。

现在最好的药材还得是野生的，还得带检测农药残留的证书。没有残留的药材，才是健康的好药材。

主持人： 头回听说生病的药材，带病治病的药材，没有农药残留的药材。药材采收有什么特别的一些……

4、抢青的 / 天麻

张老师： 现在中药效果不好，还有一个原因就是抢青。抢劫的抢，青草的青。

啥叫抢青？中药还没成熟，没到采摘季节就给收了。

为啥抢青？因为越早上市，它就能卖个好价儿。跟西瓜似的，三月份五月份多少钱一斤？七月份多少钱一斤？越早上市越能卖上价，所以很多药农就抢青。中药没成熟、没到该采收的时候，就给收了。

比如说天麻，现在很多天麻都是瘪的，为啥？它没长到时候。就跟小麦似的，灌浆都没灌满就给它收了，它能不瘪吗？瘪的天麻治疗中风、降血压，效果是真打折扣。

5、小马拉大车的 / 桔梗

张老师： 还有桔梗（润肺止咳，清热解毒，利尿消肿）。能治咽炎，能治咳嗽。

包括有的病人咳嗽时间长了，咳嗽的肋叉子都疼，是不是？这个时候在给他治病的时候，除了止咳、化痰、消炎，还得加点桔梗。

桔梗专门治咳嗽，尤其是治疗咳嗽地两边肋骨都疼这种情况，还有包括咳嗽带着肚皮都疼。加点桔梗，它也好用。

正常桔梗长个两、三年，药效才好；现在的桔梗，长一年就挖出来了，小马拉大车。你想一想，那效果能不能行？

6、未成年的 / 黄芩

张老师： 还有黄芩（清热燥湿，泻火解毒，止血安胎）。

黄芩治啥？治疗胸中痞满。什么叫痞满？心口窝这个地方堵得慌。

很多浅表性胃炎、胃病的人，胃溃疡的病人，他都心口窝这里不舒服。胃堵得慌，不得劲儿，感觉是咯咯楞楞的，像里面有东西、不舒服。这种症状，入方子的时候用黄芩是药到病除。

正常药用的黄芩，长到五寸才能用。现在可好，一寸的长就挖出来了。药材市场上全是没长大的小个黄芩，一个个跟未成年似的。咱说那孩子，20岁结婚正常。你让他10岁就结婚，能行吗？那不胡闹吗？

7、喷药、捂棉被的 / 五味子

张老师： 还有五味子（收敛固涩，益气生津，补肾宁心）。五味子这个药，敛汗。

冒汗用五味子，就好像更年期综合症这个出汗，包括平时治疗一些冠心病的病人，心里难受、冒汗。心难受，心绞痛一发作，全身冒冷汗。这个时候，少加点五味子：一个稳心率。二个能敛汗。

正常讲，五味子是十月份下霜了才收，现在七月份就收了。七月份熟了吗？没熟，还青着呢。

正常来讲，五味子是紫红色。七月份收起来是青果儿，咋办？喷药。搁棉被一捂，不见光。捂几天，就变色了，就当五味子就卖了。大伙想一想，这样的药材，它能稳心率吗？能出汗敛汗吗？不行吧。

所以说药材采摘的时候，生长年份一定要足，这样药效才有保障。就像人参：三年以下，那就是个咸菜；六年以上，才能入药；十年以下，吃了它上火；十五年以上，吃了它才会有大补，药效才是最佳的。

肆 中药炮制

张老师： 好药材的炮制也很关键。比如说熟地黄，能补血、能滋阴、能益肾填精，作用非常好。

有人吃地黄丸，吃半年都没效果。为啥？熟地黄能发挥出几成的这个功力来，对不对？得看一看：要看是不是河南产的怀地黄，还要看炮制。熟地炮制，三蒸三晒、七蒸七晒、九蒸九晒。

大部分的熟地蒸一次，三蒸三晒的都比较少，九蒸九晒的是最好的，但基本上都没有。九蒸九晒的啥样？真的是黑如漆、光如油、甘如饴。这样的好药，吃上它管事儿。

好药材是可遇不可求，好的药效更是可遇不可求。所以我也在做一些事儿，来去扭转中药效果差的局面。也希望都能用上好药，都能得到好的效果。

主持人： 今天我们又学习到了，传统医学的衰败其实当中有很大一部分的原因是药材的衰败。很多药材是被禁用，能用上的药材质量又不行，还有一些药材药效不行，因为我们用不到这个道地药材。

道地药材对原产地、种植方式、农药残留、生长年份、炮制方法都有着非常严格要求，所以就可能很难买到好的药材。但是有张老师为大家保驾护航，相信可以带来好药材，带来好效果。感谢张老师的精彩讲解。
